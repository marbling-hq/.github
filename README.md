# .github

The public profile of the Marbling organisation on GitHub.

- `profile/README.md` is what a visitor sees at https://github.com/marbling-hq.
- `profile/assets/` holds the Airmond lockup for light and dark mode, copied unchanged from `brand/logo/` in mb-airmond-brandkit, and `marbling-avatar.png`, the org avatar (1024 px square, rendered from the Marbling mark in the brandkit, the same mark marblinghq.com uses as its icon).

Change the profile with a pull request. Names or photos of people go on it only with Cédric's yes.
